# Multimodal-AI-for-Medical-Image-Classification

**Multimodal AI for Medical Image Classification: A Comprehensive Analysis of Image and Text Contributions**

## 📖 Overview

This repository contains the source code and datasets (except images) for a study analyzing the efficacy of multimodal learning in medical image analysis. By integrating visual data (clinical images) with textual information (diagnostic descriptions), we aim to improve classification accuracy compared to unimodal approaches.

Using the **MedPix 2.0 dataset**, this project systematically evaluates how combining ResNet-based image features with BERT-based text embeddings influences performance in classifying medical image locations.

## 🔬 Research Questions

To analyze the role of modality interaction and fusion design, this study addresses the following questions:

*   **RQ1:** Does the integration of clinical textual descriptions with medical images improve classification performance compared to image-only and text-only models?
*   **RQ2:** How do different multimodal fusion strategies (concatenation, modality attention, and gated fusion) influence classification performance?

## ✨ Key Contributions

*   **Dataset Construction:** We constructed a curated multimodal dataset from MedPix 2.0, pairing 2,050 clinical images with corresponding textual descriptions and labels.
*   **Fusion Framework:** We designed a deep learning framework that integrates visual representations extracted using **ResNet backbones** with contextual textual embeddings generated by **BERT**.
*   **Systematic Comparison:** We performed an ablation study across image-only, text-only, and multimodal configurations, evaluating multiple ResNet variants using Accuracy, F1-Score, ROC-AUC, and PR-AUC.
